# Open Dojo — Project Context

**Live site:** https://mydomshurt.github.io/martial-arts-gym/
**Repo:** https://github.com/MyDomsHurt/martial-arts-gym
**Hosting:** GitHub Pages (main branch root)

## What it is
A simple static website for a martial arts gym in Yau Tong, Hong Kong. Black-and-white design. Three offerings only:

- **Boxing** — coached by champions (WBC, WIBA, WBO title holders). Featured first.
- **Martial Arts Fitness** — coached conditioning.
- **Jiu Jitsu Open Mat** — unstructured community training (no coach leading the session).

## Design
Strict black and white. Oswald for headings, Inter for body. Sticky header, mobile menu, high contrast, no colour except grey shades on the schedule.

## Credit system
No contracts. Buy credits. Credits do not expire. Book up to 14 days ahead. First class is free.

- **Base:** HK$1,000 = 100 credits (HK$10 each). Larger packs include bonus credits.
- **Open Mat** (consecutive hours): 1hr = 10 credits, 2hrs = 16, 3hrs = 20.
- **Boxing & Fitness** (rolling 7-day sequential count): 1st session = 26 credits, 2nd = 19, 3rd = 16, 4th = 14, 5th+ = 13.

Open Mat does not count toward the Boxing/Fitness weekly sequence.

## Current state
Static HTML/CSS only. Contact form does not send yet (points to WhatsApp / email / phone). Coach names are still placeholders (Coach A/B/C). No real photos yet. Schedule is a weekly grid with colour-coded cells and rowspan for multi-hour blocks.
